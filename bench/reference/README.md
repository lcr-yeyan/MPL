# MPL-Bench-001 Reference Artifact

`mastering.mastered.wav` is the mastered render of `bench/baselines/mastering.mpl`,
generated by:

```text
mplc master bench/baselines/mastering.mpl -o bench/reference \
  --target-lufs -14 --peak-ceiling -1
```

It is a reference artifact for the mastering task only. It is **not** a trusted
manifest-bound render for arbitrary candidates; the verifier must bind audio via
a Render Artifact Manifest before treating it as a candidate's output.

Expected analysis after mastering:

- sample peak: -2.23 dBFS
- true peak: -2.22 dBTP
- integrated loudness: -14.00 LUFS

Verify the baseline with this artifact and its manifest:

```text
mpl_lab manifest bench/baselines/mastering.mpl \
  --audio bench/reference/mastering.mastered.wav > /tmp/mastering.manifest.json

mpl_lab verify bench/tasks/12-mastering-target.json \
  bench/baselines/mastering.mpl \
  --audio bench/reference/mastering.mastered.wav \
  --manifest bench/reference/mastering.manifest.json
```

The checked-in `mastering.manifest.json` is UTF-8 and binds the baseline source,
production, renderer configuration and mastered audio bytes. An external WAV
without a matching manifest is rejected.
