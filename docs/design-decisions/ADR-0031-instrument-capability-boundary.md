# ADR-0031：乐器能力边界

状态：已采纳（V0.3.0-rc）

## 背景

吉他等乐器有音域、复音、弦/品/指法约束。若把这些写进 Pitch/Chord 通用语义，会污染
纯音乐类型；若完全不做，又无法验证可演奏性。

## 决策

1. 新增 `InstrumentCapability`：
   - 名称、音域、最大复音数；
   - 开放弦 MIDI 列表、品数（可选）；
   - `positions(pitch)` 返回弦/品位置；
   - `fitsInstrument` 检查音域/复音。
2. 提供标准吉他配置 `guitarCapability()`：E2 A2 D3 G3 B3 E4，24 品，6 复音。
3. 乐器约束是**显式验证输入**，不进入 Pitch/Chord/HarmonyTimeline 定义。
4. 不实现完整指法求解器、手型优化或物理建模。

## 后果

- 通用和声/声部连接保持乐器无关。
- 需要吉他可演奏性时可显式查询。
- 指法搜索留给后续或外部工具。
