# ADR-0004：显式上下文依赖与逐音符溯源

状态：已采纳（V0.0.2）

## 背景

V0.0.1 的依赖图只包含“片段由哪些片段生成”，没有表达“算子读取了项目调号或拍号”。修改上下文时无法安全失效；Trace 也只能说明片段级来源，无法回答某个音符由哪个算子生成。

## 决策

1. 上下文只包含 `Key` 与 `Meter`，保存在 Music IR 内，并写入 trace。
2. 节点类型声明上下文依赖：
   - `diatonicTranspose` / `harmonize` → key；
   - `syncopate` → meter。
3. 修改上下文只失效声明对应依赖的节点及其下游，而不是整图。
4. `Note` 增加 `origin` 编译期元数据；复制型算子原样传递，`harmonize` 把生成音标记为自身。
5. Trace 输出 IR 对象表、clip 的 `derivation` 链路与逐音符 `origin`。

## 后果

- 增量重算范围可解释、可测试。
- 逐音符来源可追踪到字面量或生成算子。
- 限制：origin 只保存直接引入者，完整路径需结合 derivation；上下文种类仍然很少。
