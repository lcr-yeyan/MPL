# ADR-0023：有界节奏代数与有理周期

状态：已采纳（V0.3.0-beta）

## 背景

节奏代数需要精确处理周期、相位、负偏移、跨边界事件与不同周期的对齐。若不设边界，LCM 与 repeat/subdivide 可能产生巨大整数或无界事件展开。

## 决策

1. 所有时间使用 `Rational`；不引入浮点中间值。
2. 周期/相位：
   - `rotate` 使用正模，负 amount 规范到 `[0, L)`；
   - 跨周期事件被精确切分，而不是截断或丢弃；
   - `shift` 线性平移且允许负 onset；负 onset 不能与音高组合。
3. 共同周期：
   - `lcm(a/b, c/d) = lcm(a,c) / gcd(b,d)`（已约分）；
   - 提供 `rationalLcm`，返回 `optional<Rational>`；
   - 任何输入/结果分子或分母超过 `1e9` 返回 nullopt，关系算子报 `rhythm-period-overflow`。
4. 容量契约：
   - 事件数 ≤ 4096；
   - repeat ≤ 256；
   - subdivide ≤ 64；
   - 单事件旋转切分 ≤ 256 段；
   - 超出报诊断或抛 `mpl::Error`，不静默截断。
5. 量化/网格匹配：
   - 吸附到最近 grid 倍数，平局向正无穷；
   - quantize 与 grid 关系算子共用同一规则；
   - 不自动合并同 onset 事件。
6. `realign` 只接受周期的正整数倍，避免隐式截断或补齐。

## 后果

- 3/8 与 7/8 可精确对齐到 21/8。
- 周期运算不会造成整数溢出或无界展开。
- 有意的重叠、负 offset 与跨边界持续被保留。
- 概率节奏、humanize 与风格模型不在本 ADR 范围。
