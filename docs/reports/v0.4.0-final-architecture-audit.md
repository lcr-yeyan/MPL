日期：2026-11-25

## 0. 结论

**工程发布状态：V0.4.0 Final 可发布。**

- Compiler 0.4.0；Language 0.3.0；Stdlib 0.3.0 冻结；
- 322/322 测试通过（Debug & Release）；
- MRP-001 产物与 extent 稳定；
- LCP v1.1、Context Freeze、Trusted Render、Frame、Repair、Statistics 可复现。

**实证研究状态：已完成开发集 Learnability 与探索性 Pilot，尚未完成确认性 held-out。**

- 117 次真实模型调用；
- Learnability v1/v1.1 完成；
- 六组 Pilot 30/30 通过，但存在 ceiling effect，不能作为表示机制比较结论；
- held-out 未参与 Prompt 调优，也未执行正式评价。

工程发布与实证完成状态必须分开引用。

## 2. Language Context Package

- `lcp/v1` 与 `lcp/v1.1` 版本化，不覆盖；
- Core / Stdlib 分离；B 组不接收 stdlib；
- 所有示例通过 `mplc check`；
- 每个组件、变体、示例均有 SHA-256；
- Token 估计方法为 `ceil(UTF-8 bytes / 4)`，非精确 tokenizer；
- `bench/context-freeze.json` 固定 context/prompt/task 配置。

v1.1 修正：

- 禁止列表索引的明确说明；
- 编辑任务保留标识符；
- 合法 `cycle(R, voicingNotes(V), velocity)` 示例。

## 3. Failure Attribution

`mpl_lab model` 与 `mpl_lab verify` 记录：

- 首次/最终状态；
- syntax / type / compilation / target / preserve / frame / validity；
- Token、延迟、尝试次数；
- 原始候选与诊断。

Learnability：

- L0 0/6、L1 2/6、L2 v1 3/6 → v1.1 5/6、L3 4/6 → 5/6；
- 唯一稳定失败：local-edit frame 越权（track Piano→Keys）；
- prompt-v2 明确标识符后单次 B0 pass。

Smoke failure audit：`docs/reports/smoke-failure-audit.md`。

## 4. Trusted Execution

- `renderTrusted` 自动渲染 WAV 并生成 manifest；
- FNV 快速身份 + SHA-256 内容身份；
- 外部 WAV 没有匹配 manifest 不得作为候选渲染；
- 哈希不是签名，不证明执行来源；
- 正式实验音频由 Harness 受控渲染（当前 pilot 未使用音频任务）。

## 5. Model Accessibility

- `OpenAiCompatibleAdapter` 可用；
- 端点：DeepSeek；请求 `deepseek-chat`，返回 `deepseek-flash`；
- 117 calls、264,999 tokens、169,828 ms；
- key 仅环境变量，不写入产物；
- key 已在对话中暴露，建议轮换。

## 7. Pilot

5 tasks × 6 arms：

- A0/A1/B0/B1/C0/C1 均 5/5 pass；
- 总 30/30、77,418 tokens、41,171 ms；
- 每个 prompt 都包含精确 target，模型基本转录，ceiling effect；
- 配对差异 0，bootstrap 95% CI [0,0]；
- 不能据此声称 Flat 或 MPL 更优。
