# V0.5.0-beta Release Audit — Musical Language Foundations

日期：2026-11-25  
版本：Compiler **0.5.0-beta**、Language **0.4.0**、Stdlib **0.4.0**

## 1. 新增语言能力

### 1.1 列表索引与切片（B1）

```text
P[0]       // 0-based, Int
P[1:3]     // half-open [1,3)
P[:2]      // [0,2)
P[1:]      // [1,length)
P[:]       // copy
```

- 0 起点；负索引/负边界不支持（`index-negative`）；
- 越界 `index-out-of-range`；`start > end` 为 `index-slice-bounds`；
- `end > length` clamp；`start > length` 报错；
- 无 step/负步长；
- 值语义；O(1) 索引、O(k) 切片；结果上限 1024；
- 普通列表切片与音乐时间切片严格分离。

### 1.2 Tie（B2）

```text
tie(first, second)
```

- 显式连接 first 边界最后一个音与 second 边界第一个音；
- 同音高、唯一边界音；合并为一个逻辑 Note；
- 普通相邻同音高不自动合并；
- `tie-empty` / `tie-pitch` / `tie-ambiguous`；
- MIDI 一个 note-on；跨拍号 span 保留；
- 不产生 orphan continuation。

## 3. 音乐计算闭包结论

- 新列表索引/切片使 03、07、08 可直接表达；
- 02、04 共享同一缺口：**列表 append/fold/filter**，不是两个专用音乐函数；
- 下一步优先研究通用列表组合能力（B6 设计），不添加任务专用内建；
- 没有引入无界递归、通用高阶函数或完整泛型。

## 8. 已知限制

- 列表不支持负索引/step；空列表元素类型推导为 Number；
- 没有 append/filter/fold/map；
- tie 不支持链式专用语法、voice id、跨 clip、second origin 独立保留；
- tie 的音频运行时未单独渲染测试；MIDI note-on 已验证；
- SMA 01 的 interval 值没有直接观察接口；02/04 不可完整表达；
- 契约前置条件未全部机器执行；
- 未做 V0.5 held-out 或真实模型实验。
