## 4. 冻结与产物

- `bench/freeze.json`：任务/基线/参考/schema SHA-256、版本、环境；
- MRP-001：10 whole、144 objects、4 modules、4 tracks、14 clips、247 notes、
  921,818 帧；Sample Peak -3.64 dBFS、True Peak -3.26 dBTP、Integrated -15.69 LUFS；
- mastering 参考 WAV + SHA-256 manifest；
- 真实模型调用 117 次：Learnability v1/v1.1、prompt-v2、30 次六组 Pilot；264,999 tokens；
- 六组 Pilot 有 ceiling effect（30/30），不作为确认性结论；held-out 未参与。
