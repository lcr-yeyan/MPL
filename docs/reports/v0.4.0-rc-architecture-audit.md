# V0.4.0-rc Architecture Audit

日期：2026-11-25

## 1. 结论

V0.4.0-rc 冻结 V0.4.0-beta 的音乐语言能力，完善实验可信性：

- 编译/语言/标准库/benchmark/observation/protocol 版本冻结；
- Frame Contract 覆盖、原因授权与未覆盖语义审计；
- 受控自动渲染 + SHA-256 manifest；
- 供应商无关 adapter（离线静态 + 可选 OpenAI-compatible HTTP）；
- 有界修复循环与失败分类；
- G0–G3 泛化层级；
- 配对 bootstrap 统计。

当前全量测试 **322/322**（Debug & Release），V0.4.0-beta 的 309 项全部保留。

**真实模型实验已执行：117 次调用（2 轮 Learnability + 30 次六组探索性 Pilot）。**
Pilot 存在 ceiling effect，不作为确认性模型成功率。

## 3. Phase B：Experimental Protocol

- A0/A1：Flat Event JSON；
- B0/B1：MPL Core，禁止直接/间接 stdlib；
- C0/C1：MPL + stdlib；
- 因素：表示机制、标准库、验证反馈；
- 共同任务集合与能力矩阵冻结于 `docs/experimental-protocol.md`；
- not-applicable 不进入共同成功率；
- 同一任务实例按 experiment/task 配对。

## 4. Phase C：Frame Completeness

- `frameCoverage()` 明确 5 类对象、17 个属性、`objectIds` 未覆盖；
- 授权规则支持 `cause: direct/dependency/unknown`；
- 新增/删除/重命名/身份变化由 Semantic Delta 表达；
- 未覆盖规则 → `frameStatus=unverifiable`；
- 新增对象、越权编辑、direct-vs-dependency、未覆盖规则均有负例。

## 5. Phase D：Trusted Execution

- `renderTrusted`：Frontend → Compiler → ReferenceAudioBackend → WAV → manifest；
- SHA-256：source/module/production/asset/audio；
- 保留 FNV 快速内部身份；
- manifest 与渲染实际字节绑定；
- `mpl_lab verify --audio` 强制 `--manifest`；
- 哈希不是签名，也不证明执行正确性。

## 6. Phase E：Model Adapter

- `ModelAdapter` 供应商无关接口；
- `StaticModelAdapter` 离线导入；
- `OpenAiCompatibleAdapter` 可选 HTTP：
  - key 只从 `MPL_MODEL_API_KEY`；
  - base URL/model 从环境；
  - 不记录 key；
- 未进行 API 调用。

## 7. Phase F：Bounded Repair

- 固定 task，不放松 target/preserve/frame/tolerance；
- 反馈：诊断、失败观察、Semantic Delta；
- held-out redaction：expected 与 before/after 移除；
- 失败分类：model/compile/task/infrastructure/budget；
- 每轮候选与验证证据保留；
- 预算：attempts/tokens/wall-clock。

## 8. Phase G：Generalization

- G0 已知任务新参数；G1 已知算法新素材；G2 未知算法组合；G3 无直接解法；
- 映射：`bench/generalization.json`；
- dev/pilot/heldout split 冻结；
- held-out 参考解不进入模型上下文。

## 9. Phase H：Pilot

执行了 117 次真实模型调用：

- 8 次 smoke（3 pass / 8）；
- Learnability v1：40 calls，L0 0/6、L1 2/6、L2 3/6、L3 4/6、L4 4/6；
- Learnability v1.1：38 calls，L0 0/6、L1 2/6、L2 5/6、L3 5/6、L4 5/6；
- local-edit prompt-v2：1 call，pass；
- 六组 Pilot：30 calls，A0/A1/B0/B1/C0/C1 各 5/5 pass。

Pilot 的每个 prompt 都给出了精确 target，模型基本是转录，存在明显 ceiling effect；
不能据此比较 Flat 与 MPL 表示，也不构成确认性模型能力结论。

Learnability 显示 LCP 示例/禁止项对可学习性有影响（L2 3/6→5/6），并暴露
local-edit 的 frame 越权与 voice-leading 的列表索引幻觉。

详见 `docs/reports/pilot-experiment-v0.4.0-rc.md` 与 `bench/results/`。

## 12. 限制

- 真实模型 API 已调用 117 次；Pilot 有 ceiling effect，held-out 未参与；
- OpenAI-compatible adapter 未做真实网络验证；
- 参数化 bench 为固定 seed 冻结实例，不是运行时生成器；
- Frame 未覆盖资产文件字节与音频（由 Render Manifest 处理）；
- bootstrap 是描述性区间，不构成确认性统计；
- 不声称哈希是签名或执行正确性证明。

## 13. 结论

基础设施已能：区分表示机制、标准库与反馈；拒绝 not-applicable 混入成功率；识别编译成功但
任务失败；独立验证 target/preserve/frame/validity；自动渲染并绑定 SHA-256；在有界预算下
修复且保留证据。117 次真实调用已完成；六组 Pilot 因精确 target 暴露而有 ceiling，
不能作为确认性结论。
