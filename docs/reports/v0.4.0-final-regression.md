## 4. 失败/限制

- Pilot 目标在 prompt 中完全暴露，全部通过是 ceiling effect，不是表示比较结论；
- Learnability 是开发集诊断，不是确认性统计；
- local-edit 的 frame 越权通过显式标识符 prompt 修复；
- voice-leading 的列表索引幻觉通过 LCP v1.1 修复；
- held-out 未执行，未参与 Prompt 调优；
- 无艺术质量评价；
- key 曾在对话暴露，建议轮换；产物无 key。
