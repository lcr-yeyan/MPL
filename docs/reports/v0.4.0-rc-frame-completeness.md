# Frame Completeness Report（V0.4.0-rc）

状态：审计完成；有限覆盖，已明确 unknown/unverifiable。

## 1. 覆盖范围

`frameCoverage()`：

| Object | Properties |
| --- | --- |
| track | instrument, role, assetBindings |
| clip | start, duration, symbolicEvents, instanceId, sourceObject |
| section | start, duration |
| harmony | timeline |
| production | tempo, meter, logicalExtent, mix, automation, temporalCurves |

未覆盖：

- `objectIds`：ObjectId 本身不是音乐内容；不作为 value change；
- 外部资产文件字节（当前只比较 asset id/provider）；
- 音频渲染字节（由 Render Manifest 处理）；
- 源文本格式/注释。

未覆盖属性不会被声称“未变”。Frame 规则引用未覆盖对象/属性时返回
`frameStatus=unverifiable`，不是 pass。

## 2. Direct / Dependency / Unknown

- 根模块 contentHash 改变 → `direct`；
- 根模块不变、传递依赖 resolvedHash 改变 → `dependency`；
- 无模块信息/无法归因 → `unknown`。

`FrameRule.cause` 可限制授权原因：

```json
{"object":"clip","property":"symbolicEvents","cause":"dependency"}
```

- `deny` 优先；
- 未写 cause 等于 `*`；
- 只允许 dependency 时，direct 修改失败（测试
  `FrameContractRejectsDirectChangeWhenOnlyDependencyAllowed`）；
- unknown 变化不会被自动视为 direct 或 dependency。

## 3. 对象生命周期

- 新增：`added`；删除：`removed`；
- 重命名：旧 key removed + 新 key added，两者都必须被 allow；
- 对象 ID 变化：value 不变；`instanceId` 标 `instance`，`sourceObject` 标
  `generation`；
- 不把 ObjectId 变化当作音乐内容变化，也不允许用 ObjectId 变化绕过 frame。

## 4. 作用域逃逸

- Delta 覆盖轨道/Clip/Section/和声/生产参数；修改未授权对象会失败；
- 新增对象测试：`FrameContractRejectsAddedObject`；
- 越权 Clip 测试：`FrameContractRejectsUnauthorizedClipEdit`；
- 未覆盖规则：`FrameContractReportsUncoveredRule`；
- 音频绑定绕过：Render Manifest 拒绝（见 Trusted Execution）。

## 5. Fault Injection / 负例

| 故障 | 结果 |
| --- | --- |
| 修改未授权 clip | frame failed |
| 新增 track/clip | frame failed |
| 只允许 dependency 的 direct edit | frame failed |
| frame 引用未覆盖对象 | frame unverifiable |
| allowedScope=none 修改 | fail |
| preserve 违反 | fail |
| target 未完成 | fail |
| 外部 WAV 无 manifest | verify 拒绝 / audio unverifiable |

## 6. 限制

- 共享依赖归因是模块粒度，不是表达式粒度；
- 重命名表现为 remove+add，可能导致规则需要同时允许两个方向；
- 音频/资产字节级作用域不在 frame 内；
- 新增 IR 属性必须同步更新 `frameCoverage` 与 Semantic Delta，否则只能报
  unverifiable/unknown。
